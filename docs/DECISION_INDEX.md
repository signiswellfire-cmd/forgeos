# ForgeOS Decision Index

**Document Version:** 1.2.0

**Last Updated:** 2026-08-01

---

# Purpose

This document is the authoritative navigation index for permanent engineering knowledge within ForgeOS.

Every significant engineering decision shall have exactly one authoritative document. This index exists solely to locate those documents and record their approval status. It intentionally avoids duplicating engineering knowledge.

---

# Knowledge Ownership Principle

ForgeOS follows a **Single Source of Truth** model.

Each permanent concept has exactly one authoritative owner.

Examples include:

* Vision
* Mission
* Philosophy
* Constitution
* Genome
* RFCs
* TDSs
* TDRs
* Engineering Standards

All other documents should reference these authoritative sources rather than duplicate their content.

---

# Decision Status

| Status     | Meaning                                                           |
| ---------- | ----------------------------------------------------------------- |
| Planned    | Decision identified but not yet documented.                       |
| Draft      | Engineering document exists but has not yet become authoritative. |
| Approved   | Official source of truth.                                         |
| Superseded | Replaced by a newer decision.                                     |
| Deprecated | Retained only for historical reference.                           |
